# Licensing Decision Record

## Current status

The repository is not assigned a new open-source license by this file. The current licensing position must be confirmed by the rights holder before acquisition, distribution, or IP transfer.

## Audit requirements

Before a transaction or public release, the owner should confirm whether the repository is intended to be proprietary, open source, or dual licensed. That decision must be recorded in a root `LICENSE` file or an executed transfer document, as appropriate.

## Third-party materials

The dependency tree, generated assets, Firebase configuration, fonts, media, and externally hosted services must be inventoried separately. A dependency's license does not grant rights to the original application or its brand assets.

## Legal boundary

This record is an engineering diligence artifact. It does not establish ownership, inventorship, assignment, trademark rights, or license compliance.
